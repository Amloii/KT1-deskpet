# Media / Multimedia

**EN** — Videos and photos of KT1 for the READMEs.

1. Record short clips (≤ 30 s, landscape, ideally < 10 MB; GitHub accepts up to 100 MB).
2. Open `README.md` in the GitHub web editor and **drag the .mp4** onto the slot
   (`> 🎬 Video pending …`). GitHub uploads it and inserts a
   `https://github.com/user-attachments/assets/…` link that plays inline.
3. Reuse the same link in `README.es.md`.
4. Photos (`.jpg`/`.png`) can be committed here and referenced as `docs/media/name.jpg`.

Before publishing, check that no frame shows your Wi-Fi name, IP, tokens, API keys,
notifications or the content of your PC screen.

---

**ES** — Vídeos y fotos de KT1 para los README.

1. Graba clips cortos (≤ 30 s, en horizontal, idealmente < 10 MB; GitHub admite hasta 100 MB).
2. Abre `README.es.md` en el editor web de GitHub y **arrastra el .mp4** sobre el hueco
   (`> 🎬 Vídeo pendiente …`). GitHub lo sube e inserta un enlace
   `https://github.com/user-attachments/assets/…` que se reproduce en la página.
3. Reutiliza el mismo enlace en `README.md`.
4. Las fotos (`.jpg`/`.png`) se pueden subir a esta carpeta y enlazar como `docs/media/nombre.jpg`.

Antes de publicar, revisa que en ningún fotograma se vea el nombre de tu Wi-Fi, tu IP,
tokens, claves de API, notificaciones o el contenido de la pantalla de tu PC.
